# trabalho-objetos-de-aprendizagem

## Público Alvo
O Objeto de Aprendizagem é destinado a Estudantes de Graduação (Ciência da Computação, Sistemas de Informação ou Análise e Desenvolvimento de Sistemas) que estão cursando a disciplina de Banco de Dados I ou II, além de Profissionais de Tecnologia em Início de Carreira (Devs Junior e Analistas de Dados Trainee).

## Requisitos de Aprendizagem

1. Compreender os conceitos de JOINs em SQL

    Introdução aos conceitos de INNER JOIN, LEFT JOIN, RIGHT JOIN e FULL OUTER JOIN. E formas de utilização em problemas reais.
    Avaliação:
        Explicação de forma de utilização de JOIN.
        Questões de múltipla escolha para validação dos conceitos de JOIN.
    Taxonomia de Bloom: Compreender

2. Aplicar JOINs em consultas SQL

    Construir consultas utilizando corretamente INNER JOIN, LEFT JOIN e RIGHT JOIN em cenários práticos.
    Avaliação:
        Exercícios práticos em banco de dados
    Taxonomia de Bloom: Aplicar

3. Analisar resultados de diferentes tipos de JOINs

    Comparar os resultados retornados por diferentes JOINs em um mesmo conjunto de dados.
    Avaliação:
        Análise de saídas de queries
        Questões que pedem explicação de resultados divergentes
    Taxonomia de Bloom: Analisar

4. Avaliar o uso de JOINs vs Subconsultas Correlacionadas

    Decidir quando utilizar JOINs ou correlated subqueries considerando desempenho e legibilidade.
    Avaliação:
        Comparação entre duas soluções SQL
        Justificativa escrita da melhor abordagem
    Taxonomia de Bloom: Avaliar

5. Criar consultas SQL complexas

    Desenvolver consultas que combinem múltiplos JOINs e subconsultas correlacionadas para resolver problemas mais complexos.
    Avaliação:
        Desafio final
         Problema aberto com múltiplas tabelas
    Taxonomia de Bloom: Criar
